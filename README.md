

# 📡 Ultra-Wideband (UWB) Microstrip Patch Antenna

## Overview

This project presents the design and simulation of an **Ultra-Wideband (UWB) Microstrip Patch Antenna** using **ANSYS HFSS**. The antenna is designed on a **Jean substrate** to achieve wide impedance bandwidth, improved return loss, and stable radiation characteristics. Slotting techniques are incorporated into the patch to enhance the antenna's operating bandwidth while maintaining a compact and lightweight structure.

The antenna is suitable for modern wireless communication systems requiring high data rates, low power consumption, and wide frequency coverage.

---

## Antenna Design

The antenna consists of a microstrip patch fed by a microstrip transmission line on a **Jean substrate**. The slot configuration modifies the surface current distribution, creating multiple resonant modes that significantly improve impedance matching and bandwidth.

---

## Simulation Results

The antenna was designed and analyzed using **ANSYS HFSS**. Simulation results demonstrate wideband performance with multiple resonant frequencies and good impedance matching throughout the operating band.
